#Descripción del proyecto
Este es el primer trabajo para la materia computación III. 
El objetivo de este curriculum vitae fue poner en práctica y consolidar todos los conocimientos vistos en clases, en el que se utilizó HTML5, CSS Y Flexbox.

##El proyecto esta dividido en las siguientes secciones.
HEADER
Un nav: conformado por botones de navegacion directa a cada seccion importante de la página.
MAIN
Presentación personal e información: Breve resumen personal junto a una imagen.
Secciones divididas en ESPERIENCIA, un resumen de mi experiencia previa en el diseño. HABILIDADES TECNOLÓGICAS, ESTUDIOS, y una breve GALERIA DE TRABAJOS que se realizaron durante la carrera.
FOOTER
Pie de página con enlances directos a mis redes, behance y mi correo.


##Información técnica
Editor de código: Visual Studio Code
Tamaño de pantalla: 1920x1080
