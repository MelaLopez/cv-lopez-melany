# Descripción del proyecto
Esta es la continuacion del primer trabajo de la materia computación III. 
El objetivo de este proyecto es expandir el curriculum vitae y convertirlo a portafolio interactivo con varias secciones.

## El proyecto esta dividido de la siguiente manera.

Pagina web dividida en 4 secciones, Inicio, sobre mi, proyectos y contacto, siendo esta ultima la que mas se diferencia del resto del portafolio al cambiar el fondo blanco por uno completamente negro. Asimismo, la sección de "Inicio" cuenta con adaptación responsive.

## Información técnica
Editor de código: Visual Studio Code
Tamaño de pantalla: 1920x1080
